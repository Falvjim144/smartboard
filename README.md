# Smartboard — Simulador iQ 4 del CEP

Simulador educativo interactivo del panel SMART Board MX075-V5 con sistema iQ 4. Incluye **23 prácticas** para formación del profesorado.

## Web

https://falvjim144.github.io/smartboard/

## Publicación

En **Settings → Pages → Build and deployment → Source**, selecciona **GitHub Actions**. El workflow en `.github/workflows/deploy.yml` publica el sitio al actualizar la rama `main`.

El archivo `index.html` contiene todo el simulador. Las fuentes se cargan desde Google Fonts. El progreso de las prácticas se guarda en el propio navegador.
